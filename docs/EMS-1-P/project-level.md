# Project Level

| Project Level | Criteria | Estimated Total Timeline |
| ------------- | -------- | ------------------------ |
| Standard Project | Uses only standard features, and all integrated devices use mainstream brands with standard protocols listed in the supported devices | 10–15 days |
| Light Customization | 1–2 minor strategy adjustments, or integration of 1 non-standard device | 15–20 days |
| Medium Customization | Addition of 1 new business strategy, or integration of 2–3 devices using non-standard protocols | 20–30 days |
| Heavy Customization | Microgrid, multi-energy integration, completely new business logic, or in-depth development based on proprietary protocols | More than 30 days, requiring separate evaluation |
