# Application Scenarios

The Multi-function Energy Meter is a brand-new micro smart meter that uses split-core current transformers for easy installation. It is suitable for monitoring the energy consumption of electrical systems, performing real-time measurement of electrical parameters in the circuit such as voltage, current, active power, power factor, frequency, and active energy, and sending the data to local or remote software platforms via WiFi, enabling detailed monitoring and analysis of energy usage.

## Applicable Scenarios

Suitable for bidirectional metering scenarios in European residential and small commercial & industrial applications:

- Remote 24-hour real-time monitoring of power consumption data to keep track of energy usage at any time.
- Local API-based device linkage control for efficient integration into HEMS.
- LoRa technology for long-distance data relay transmission, ensuring data transmission stability.
