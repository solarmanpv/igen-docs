# Product Advantages

## Product Features

- Optional LoRa for low-power, long-distance data upload.
- Split-core current transformers for easy installation and maintenance.
- Compact size, 1P width.
- Accuracy class 1.0 for active energy, class 2.0 for reactive energy.
- Bidirectional metering of consumption or generation data.
- Millisecond-level data and fault information collection.
- Built-in Bluetooth for local network configuration.
- Local API interface for efficient HEMS integration.
- Compliant with the EN 18031 IoT cybersecurity standard.
