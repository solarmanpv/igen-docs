# 产品介绍

## 1. 功能简介

EMS-1-C 专为工商业能源需求设计，覆盖光、储、充、用等多元化场景。该系列网关不仅全面支持储能特性，还实现了储能柜内各设备单元的便捷接入、高效数据汇聚、灵活协议转换、安全数据存储，以及集中监控与智能化维护等多重功能，为能源管理带来前所未有的便捷与高效。

## 2. 适用场景

适用于国内外工商业光、储、充、用能量管理应用场景：

- 设备商、集成商配套储能系统，完成储能系统中各设备单元全量接入及策略协同
- 运维人员通过本地或远程软件平台实现在线监控、安全预警，实时获取设备运行状态
- 调试人员需要对设备实现本地或远程升级，进行快速配置和调试，解决运维痛点
- 工商业主需要系统的能源管理手段，提升能源利用效率，实现增收与最优经济用能

## 3. 产品特性

- 多接口兼容性：RS485、CAN、Ethernet、DI/DO、AI、USB 等
- 多通信方式：支持通过 4G、WiFi、以太网等多种通信方式入云
- 本地化管理：内嵌 Web 管理界面，可本地登录进行查看和运维
- 多平台接入：支持数据加密传输至 Solarman 或第三方平台
- 能源策略：支持本地/远程进行能源策略配置
- 协议覆盖广：兼容多种品牌逆变器、BMS、电表的协议接入
- 安全合规性：遵循 EN 18031 物联网安全标准，具备数据加密和用户隐私保护能力
- 软硬件可升级：支持固件 OTA 升级、数据导出
