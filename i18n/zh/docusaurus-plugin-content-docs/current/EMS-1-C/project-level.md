# 项目级别

| 项目等级 | 判定标准                                           | 预估总周期            |
| -------- | -------------------------------------------------- | --------------------- |
| 标准项目 | 全部使用标准功能，接入设备均为表内标准协议主流品牌 | 10~15 天              |
| 轻度定制 | 1~2 项策略微调，或 1 款非标设备接入                | 15~20 天              |
| 中度定制 | 新增 1 类业务策略，或 2~3 款非标协议设备           | 20~30 天              |
| 重度定制 | 微网、多能互补、全新业务逻辑、私有协议深度开发     | 30 天以上，需单独评审 |
