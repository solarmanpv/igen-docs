# 设备监控平台

## 1. 能睿平台概述

本设备可接入能睿云平台，为新能源场站提供全方位的智能管理支持，通过实时数据采集、监控和分析，确保场站内光伏、储能、充电桩等设备的高效运转。同时，智能化的运维和故障预警功能有效保障了设备的稳定性和安全性，助力实现绿色低碳和经济效益双赢。

本文档简要介绍EMS所连接平台功能，详细介绍可登录[能睿官方网站](https://console.nengrui.cloud/knowledge)下载平台用户操作手册。

## 2. 登录和账号管理

### 2.1 账号

- Web端登录地址：https://console.nengrui.cloud
- 输入企业管理员（平台方）分配的账号及初始密码登录，首次登录需修改密码。登录后界面如下：

<img src={require("./img/nengrui1.png").default} />

### 2.2 个人信息设置

点击页面右下角头像进行个人设置，其中：
- 个人信息：修改头像、姓名。
- 账号与安全：可修改邮箱、手机号、用户名、登录密码及注销账号。
- 偏好设置：可设置温度单位、电量单位偏好设置，将影响页面内对应数据单位展示。

<img src={require("./img/nengrui2.png").default} />

## 3. 能睿功能介绍

### 3.1 数据看板

数据看板可以帮助运行人员和管理人员了解集团及其下级单位管理场站的整体运行情况，通过整体数据统计、图表、排名、地图等方式全方面了解场站集群的运行状况。

<img src={require("./img/nengrui3-1.png").default} />

### 3.2 数据大屏

数据大屏为场站运行人员和管理人员监控集团及下属单位光伏、储能场站集群运行状况的“中枢看板”。整合了地图、统计、图表、排名等多种方式，提供分层次、多维度的数据视图，有效支撑日常监控、效能分析、对标管理和决策制定，提升场站集群管理的透明度和效率。

<img src={require("./img/nengrui3-2.png").default} />

### 3.3 场站详情

用户可以在场站详情中看到该场站详细信息及进行相关操作，其中包含数据看板、子场站、设备、报警、视频监控和设置等模块。

从场站列表中选择一个场站，即可显示其详情页面，如下所示：

<img src={require("./img/nengrui3-3.png").default} />

#### 3.3.1 子场站

在场站详情页选择**子场站**标签。子场站适用于工商业园区多屋顶或有多个储能集装箱一体柜的场景。您可以为所有屋顶或一体柜创建多个子场站，并将属于这些屋顶或一体柜的设备转移到子场站内，子场站将能统计数据。

<img src={require("./img/nengrui3-3-1.png").default} />

#### 3.3.2 设备

在场站详情页中选择**设备**标签。设备用于管理本场站下所有设备，可支持进行设备查询、设备详情、设备控制、编辑和删除设备等操作，满足用户运维设备的需求。

<img src={require("./img/nengrui3-3-2.png").default} />

#### 3.3.3 报警

在场站详情页中选择**报警**标签。报警用于展示场站下实时报警和历史报警。

<img src={require("./img/nengrui3-3-3.png").default} />

#### 3.3.4 能量管理

在场站详情页中选择**能量管理**标签。能量管理功能用于设定EMS的每日执行策略和实时控制，实现云边一体。和常规的设备控制不一样，能量管理里的所有控制内容由标准物模型决定，设备厂商协议只能适应标准物模型的要求，不支持自定义。如设备未适配，将无法使用本模块。

<img src={require("./img/nengrui3-3-4.png").default} />
