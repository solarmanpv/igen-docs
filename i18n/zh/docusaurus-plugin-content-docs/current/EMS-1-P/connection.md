# 线缆连接

## 1. RS485 / CAN 通讯接线

1. 剥除双绞通讯线接线端 8~10 mm 的外皮。
2. 套入合适规格的管型端子，并使用压线钳压接牢固。
3. 使用 2.5 mm 一字螺丝刀顶压接线口上方的压簧，将管型端子插入接线孔，直至端子的绝缘护套完全进入接线端子，松开螺丝刀压紧管型端子。
