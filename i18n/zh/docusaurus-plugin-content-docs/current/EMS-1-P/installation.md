# 设备安装

## 1. 安装前检查

- 在安装控制器前，请仔细检查控制器外壳是否存在变形、进水等问题。
- 为控制器上电前，请仔细检查线束是否存在外观变形破损、连接器损坏等问题。线束连接请按照下述指导进行，确保各节点连接稳固。

:::warning
请保证 PE 端稳固接地，接地电阻 \< 0.1 Ω，否则存在巨大的电流泄露风险和安全隐患。
:::

## 2. 安装EMS

设备安装尺寸如下图所示（单位：mm）：

<img src={require("./img/installation_size.png").default} width="480"/>

请依据您的具体部署环境与需求，选择以下相应的安装方式。

### 2.1 直装式

通过 EMS 底部两侧的安装支架，安装于提前开好螺纹孔（M4）的电气安装板上，接口面朝下。

<img src={require("./img/installation1.png").default} width="480"/>

### 2.2 壁挂式

1. 首先，使用 ⌀6mm 冲击钻头在墙体上进行钻孔，钻深 30mm 以上。
<img src={require("./img/installation2-1.png").default} width="320"/>

2. 敲入膨胀塑料管，确保膨胀塑料管能完全嵌入墙体。
<img src={require("./img/installation2-2.png").default} width="320"/>

3. 通过EMS底部两侧的安装支架，用自攻螺丝（M4）将EMS固定于墙面上，接口面朝下。
<img src={require("./img/installation2-3.png").default} width="320"/>


### 2.3 卡扣式

1. 拆除两侧安装支架，安装配件中的导轨卡扣到 EMS 背面。
<img src={require("./img/installation3-1.png").default} width="480"/>

2. 将EMS安装于规格 TH35-7.5 导轨上，接口面朝下。
<img src={require("./img/installation3-2.png").default} width="240"/>
