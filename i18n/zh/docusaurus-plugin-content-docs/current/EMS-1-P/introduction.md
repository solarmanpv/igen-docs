# 产品介绍

## 1. 功能简介

EMS-1-P 工商业能源管理中心系列是围绕工商业能源需求，光、储、充、用等场景所设计的，支持储能特性，支持储能柜内各设备单元接入、数据汇聚、协议转换、数据存储、集中监控和维护等日常控制功能，同时支持削峰填谷、需量控制、备电管理、防逆流、新能源消纳等多种储能基础策略。

## 2. 适用场景

适用于国内外工商业光、储、充、用能量管理应用场景：

- 工商业业主用 EMS-1-P 统计分析能源、优化管理，实现增收与最优经济用能。
- 安装调试人员用于安装、配置、调试产品，提供全量、快速的接入能力。
- 支持运维人员本地/远程监控管理、告警处理，获取设备与系统实时运行情况。
- 三方设备商、集成商等对接、调试设备，利用可视化UI界面，直观清晰。

## 3. 产品特性

- 多接口兼容性：RS485、CAN、Ethernet、DI/DO、AI/AV、USB、HDMI 等。
- 多通信方式：支持通过 4G、Wi-Fi、以太网等多种通信方式入云。
- 本地化管理：内嵌 Web 管理界面，可本地登录进行查看和运维。
- 多平台接入：支持数据加密传输至 Solarman 或第三方平台。
- 能源策略：支持本地/远程进行能源策略配置。
- 协议覆盖广：兼容多种品牌逆变器、电表、BMS的协议接入。
- 安全合规性：遵循 ETSI EN 303 645 国际安全标准，具备数据加密和用户隐私保护能力。
- 软硬件可升级：支持固件 OTA 升级、数据导出。
- 强扩展性：预留 SD 卡插槽支撑扩展。
