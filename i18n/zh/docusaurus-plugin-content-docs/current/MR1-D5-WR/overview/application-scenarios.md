# 应用场景

多功能电能表是一款全新的微型智能电表，采用开口式互感器接入，便于安装，适用于监控电气系统的能耗，对线路中的电压、电流、有功功率、功率因数、频率、有功电能等电量参数进行实时计量，并通过 WiFi 无线方式将数据发送到本地或远程软件平台，实现电能使用的详细监测与分析。

## 适用场景

适用于欧洲户用和小型工商业双向计量场景：

- 需要远程 24 小时实时监控用电数据，随时掌握电能消耗。
- 需要实现本地 API 设备联动控制，高效接入 HEMS。
- 利用 LoRa 技术进行远距离数据中继传输，保障数据传输稳定性。
