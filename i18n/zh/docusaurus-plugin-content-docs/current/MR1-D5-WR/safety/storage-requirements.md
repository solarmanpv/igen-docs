# 存储要求

如果电表不立即投入使用，则存储时需满足：

- 请勿拆除外包装，并且定期检查（推荐 3 个月检查一次）。如发现有虫蛀咬、包装损坏，请及时更换包装。如果已拆开外包装且不立即投入使用，将其装入其原始包装内，并用胶带进行密封。
- 存储环境的温度和湿度适宜（存储温度：-40℃~+90℃、相对湿度：≤40%RH，无凝露）。环境空气中不可含有腐蚀性或易燃性气体。
- 存放在清洁干燥的地方，并防止灰尘及水汽的侵蚀。禁止遭受雨水或地面积水侵蚀。
- 存储时间在两年及以上时，电表需经过专业人员的检查和测试才能投入使用。
